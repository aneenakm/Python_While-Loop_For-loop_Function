# Python Assignment Using While Loop, For loop and Function

A beginner-friendly Python assignment completed in a single Jupyter Notebook. This notebook contains three programs to practise loops, control statements, functions, and basic mathematical calculations.

## 📌 Programs Included

### 1. Number Guessing Game
- Generates a random number between 1 and 10.
- Allows three valid guesses.
- Provides hints when the guess is too high or too low.
- Demonstrates `while`, `continue`, `break`, and `while-else`.

### 2. Multiplication Table Generator
- Accepts a number from the user.
- Prints its multiplication table from 1 to 10.
- Demonstrates `for` loops and the `range()` function.

### 3. BMI Calculator
- Accepts weight in kilograms and height in meters.
- Calculates Body Mass Index (BMI) using a custom function.
- Demonstrates function parameters and the `return` statement.
- Validates positive weight and height.
- Displays the BMI to two decimal places.

## 🛠️ Technologies Used

- Python
- Jupyter Notebook
- `random` module
- Loops and conditional statements
- Functions and basic calculations

## ▶️ How to Run

1. Download or clone this repository.
2. Open `Python_Assignment3.ipynb` in Jupyter Notebook or Visual Studio Code.
3. Run the cells in order.
4. Enter the requested inputs when prompted.

**Requirement:** Python 3 and Jupyter Notebook support.

## 🎯 Learning Objectives

- Understand `while` and `for` loops.
- Practise `break`, `continue`, and loop `else`.
- Create and call Python functions.
- Perform mathematical calculations.
- Validate user input.
